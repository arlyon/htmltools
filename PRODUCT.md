# Product

## Register

product

## Users

A single primary user managing personal and professional commitments in an Obsidian vault. They review the interface on desktop to understand every active commitment, identify the next executable action, notice external dependencies, and catch approaching deadlines.

## Product Purpose

htmltool turns portable HTML files into local, filesystem-aware applications. Open Loops is its reference tool: a dense operational view over raw Obsidian Markdown that makes commitments visible without creating a second source of truth. Success means the user can scan the full state of their open loops quickly and return directly to the originating note.

## Brand Personality

Direct, rigorous, composed. The interface should communicate operational control through clear hierarchy and compact information, without creating visual urgency where none exists.

## Anti-references

Corporate admin dashboards with generic card grids, KPI tiles, oversized navigation, decorative gradients, glass effects, or enterprise chrome. The interface should also avoid turning the review into a gamified checklist.

## Design Principles

1. The note remains the source of truth. Present and navigate Obsidian data rather than duplicating it.
2. Optimize for comparison across commitments. Stable columns and grouping should make gaps and exceptions obvious.
3. Prefer density with hierarchy. Show substantial information at once, but use alignment, typography, and restrained color to preserve scanability.
4. Make missing next actions visible. Empty operational fields are meaningful signals, not details to hide.
5. Use status color semantically and sparingly. Most of the surface should remain quiet enough for exceptions to stand out.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support complete keyboard navigation, visible focus states, sufficient text and non-text contrast, semantic table structure, zoom and narrow viewport reflow, and reduced-motion preferences. Never rely on color alone for status or priority.
